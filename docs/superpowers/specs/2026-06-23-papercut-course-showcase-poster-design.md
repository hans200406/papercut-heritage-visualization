# 纸上生花课程成果总览海报设计规格

## 目标

为《信息可视化》课程设计生成一张竖版成果总览海报，用于最终提交包中展示项目主题、数据结论、模块成果和视觉风格。海报优先服务课程作业检查，要求信息完整、结构清楚，同时保持“新中式文化展览”的视觉气质。

## 输出

- 主输出文件：`poster_course_showcase.png`
- 建议尺寸：`1080 x 1920`
- 辅助文件：保留可编辑 HTML/CSS 生成源文件，方便后续修改文字或截图。

## 版式

海报采用自上而下的成果总览结构：

1. 顶部主视觉区
   - 项目眉题：`数字遗珍 · 中国剪纸`
   - 主标题：`纸上生花`
   - 副标题：`中国剪纸非遗多维信息可视化设计`
   - 放置红色剪纸对称图形，形成第一视觉焦点。

2. 数据概览区
   - 三个指标：`54 个剪纸类项目`、`22 个省级地区`、`40% 模块 A 权重`
   - 指标下方放三条简短发现：地域分布、批次结构、民族纹样关键词。

3. 模块成果区
   - 模块 A：非遗数据分析信息可视化设计
   - 模块 B：剪纸图形艺术信息可视化设计
   - 模块 C：文化叙事与交互整合设计
   - 每个模块使用项目现有截图或聚焦截图作为成果证据。

4. 底部说明区
   - 标注课程名称、项目主题和数据来源说明。

## 视觉风格

- 背景：暖米纸色，带轻微纸张质感。
- 主色：朱砂红 `#b21f2d`。
- 辅色：深纸红 `#7d1420`、墨褐 `#251714`、米纸色 `#fffaf2`、淡金 `#c99742`。
- 字体：系统中文字体，优先使用 `Microsoft YaHei`。
- 图形语言：对称、镂空、团花、窗花等剪纸视觉特征。
- 避免：照片拼贴、蓝色商务 dashboard、过多渐变、装饰遮挡信息。

## 验收标准

- 输出图片尺寸为 `1080 x 1920`。
- 海报能清楚识别标题、主题、三项指标、三条发现和三个模块成果。
- 截图不变形、不被严重裁切，文字不互相遮挡。
- 视觉风格与网页和课程设计说明书一致。
- 文件保存到项目根目录，便于用户自行打包提交。
